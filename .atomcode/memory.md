- zig cc 0.17-dev 在无 -O（debug 模式）下编译 C 代码会默认注入 UBSan（__ubsan_handle_*），交叉编译静态库必须显式加 -O2/-O3；且 zig 交叉编译时 curl 等 CMake 项目会经 pkg-config 混入宿主机库（/opt/local），需 PKG_CONFIG_LIBDIR 指向空目录。
